# Daily Expense Tracker

## 1. About the Project

Daily Expense Tracker is a simple mini project developed using HTML and CSS. It provides a user-friendly interface to manage and view daily expenses.

The main purpose of this project is to help users understand their spending habits and organize their expenses.

## 2. Objectives

- To create a simple expense tracking interface.
- To display daily expense details.
- To show total expenses and transactions.
- To organize expenses by category.
- To design a clean and responsive webpage.

## 3. Technologies Used

- **HTML5:** Used to create the structure of the webpage.
- **CSS3:** Used to design and style the webpage.

## 4. Features

- Simple and attractive user interface.
- Expense entry form.
- Different expense categories.
- Expense history table.
- Total expense summary section.
- Category-wise expense section.
- Responsive design for mobile screens.

## 5. Expense Categories

The project includes the following categories:

- Food
- Travel
- Shopping
- Education
- Bills
- Entertainment
- Other

## 7. How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Find the `index.html` file.
4. Open it in any web browser.
5. The Daily Expense Tracker webpage will appear.

## 8. Team Members

This project is divided among three members:

- **Member 1:** HTML structure and form design.
- **Member 2:** CSS styling and responsive design.
- **Member 3:** Project documentation and testing.

## 9. Project Limitations

This version is developed using only HTML and CSS.

- Expenses cannot be added dynamically.
- Total expenses are not calculated automatically.
- Delete and filter buttons are not functional.
- Data is not stored.

These features can be added in future versions using JavaScript.

## 10. Future Improvements

- Calculate total expenses automatically.
- Add and delete expense records.
- Add category filters.

- Add monthly expense reports and charts.

The Daily Expense Tracker mini project demonstrates the use of HTML and CSS to create a simple and responsive webpage. It also helps us understand basic web development concepts and teamwork.
